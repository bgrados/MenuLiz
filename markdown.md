Construye una PWA completa llamada "MenuLiz" para un restaurante en Perú que vende almuerzos (menú del día y platos a la carta). Usa Next.js 14 App Router, TypeScript, Tailwind CSS, Shadcn UI, Supabase (PostgreSQL + Auth + Storage), next-pwa, Lucide React, React Hook Form, Zod, date-fns, html2canvas. Todo el texto en español peruano, moneda S/ (Soles). El menú completo (1 Entrada + 1 Segundo + 1 Refresco) cuesta S/ 14 fijo. El cliente puede pedir parcial: solo 1 segundo, solo entradas, 2 entradas + 1 segundo, etc. Si detecta combo completo aplica S/ 14, si es parcial suma precios individuales. Los platos a la carta tienen precio propio. Stock limitado por plato por día, si se agota mostrar "AGOTADO" y deshabilitar. No hay pagos online, solo referencia: Efectivo, Yape, Plin, Lemon. No hay registro de clientes, solo piden con nombre y teléfono. La dueña tiene login con email/password. El pedido se envía generando un mensaje de WhatsApp automático al número de la dueña. Las categorías de platos son: entrada (2-3 opciones por día), segundo (4-5 opciones por día), refresco (1-3 opciones por día), a_la_carta (cualquier cantidad). Crea el módulo cliente público sin registro con: Landing (/) mostrando nombre "MenuLiz", fecha de hoy, 2 botones "Ver Menú del Día" y "Ver Platos a la Carta", diseño mobile-first color primario naranja #f97316. Página /menu que muestra solo platos disponibles hoy con stock mayor a 0 agrupados por Entradas, Segundos, Refrescos, cada plato con foto, nombre, descripción, badge "AGOTADO" si no hay stock, el cliente selecciona múltiples items y cantidades, el total se calcula automáticamente detectando combo completo S/ 14 o sumando precios individuales, botón "Agregar al carrito". Página /carta con platos a la carta disponibles hoy, foto, nombre, descripción, precio, selector de cantidad, badge agotado. Página /carrito con lista de items modificables, tipo de entrega Delivery (pedir dirección + costo extra) o Recojo en local, datos del cliente nombre, teléfono, dirección solo si delivery, método de pago Efectivo Yape Plin Lemon, notas opcionales, resumen subtotal + delivery = total, botón "Confirmar Pedido". Al confirmar se guarda el pedido en Supabase, se descuenta stock automáticamente, se genera mensaje WhatsApp con formato: "🍽️ NUEVO PEDIDO - MenuLiz, fecha, cliente, teléfono, tipo entrega, dirección si aplica, lista de platos con cantidad y precio, subtotal, delivery, total, método de pago, notas", se abre wa.me con el mensaje prellenado al número de la dueña y se muestra pantalla de confirmación. Crea el módulo admin protegido con login de Supabase Auth con: Login (/login) email y password. Layout admin con sidebar Dashboard, Platos, Menú Hoy, Pedidos, Compartir, responsive bottom nav en móvil, botón cerrar sesión. Dashboard (/admin/dashboard) con cards de pedidos hoy, ingresos hoy, pendientes, completados y últimos 5 pedidos. Página /admin/platos con CRUD completo, campos nombre, descripción, precio, categoría, foto con upload a Supabase Storage bucket "dish-images", toggle activo/inactivo, grid de cards, filtrar por categoría. Página /admin/menu-hoy con date picker default hoy, mostrar platos activos agrupados por categoría, checkbox para seleccionar cuáles van hoy, input numérico para stock disponible por plato, guardar/editar menú del día, preview de cómo lo verá el cliente. Página /admin/pedidos con lista en tiempo real usando Supabase Realtime, filtro por estado, cada pedido muestra cliente, teléfono, items, total, pago, hora, botones para cambiar estado: nuevo, confirmado, en_preparacion, en_camino, listo_para_recoger, completado, opción cancelar. Página /admin/compartir que genera una card visual del menú de hoy con logo, fecha, secciones y precios, botón "Copiar Link", botón "Descargar Imagen" usando html2canvas, botón "Enviar por WhatsApp" con texto y link. Configura next.config.js con next-pwa (dest public, cacheOnFrontEndNav true, aggressiveFrontEndNavCaching true, reloadOnOnline true) y remotePatterns para imágenes de supabase.co. Crea el manifest con name "MenuLiz - Pedidos Online", short_name "MenuLiz", theme_color #f97316, display standalone, icons 192 y 512. Variables de entorno: NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_ANON_KEY, SUPABASE_SERVICE_ROLE_KEY, NEXT_PUBLIC_SITE_URL, NEXT_PUBLIC_WHATSAPP_NUMBER, NEXT_PUBLIC_RESTAURANT_NAME=MenuLiz, NEXT_PUBLIC_MENU_PRICE=14. Crea el cliente de Supabase para browser con createBrowserClient de @supabase/ssr, para server con createServerClient y cookies, y admin con service role key sin persistir sesión. Crea la estructura de carpetas: app/(customer)/layout.tsx, page.tsx, menu/page.tsx, carta/page.tsx, carrito/page.tsx, confirmacion/page.tsx, app/(admin)/login/page.tsx, app/(admin)/admin/layout.tsx, dashboard/page.tsx, platos/page.tsx, menu-hoy/page.tsx, pedidos/page.tsx, compartir/page.tsx, app/manifest.ts, app/layout.tsx, app/globals.css, components/ui/, components/admin/, components/customer/, components/shared/, lib/supabase/client.ts, server.ts, admin.ts, lib/utils.ts, lib/constants.ts, lib/whatsapp.ts, types/index.ts, hooks/use-cart.ts, hooks/use-daily-menu.ts, stores/cart-store.ts. El hook use-cart debe manejar addItem, removeItem, updateQuantity, clearCart, calcular subtotal, detectar combo completo (1 entrada + 1 segundo + 1 refresco) y aplicar precio S/ 14, items extra se cobran a precio individual. El hook use-daily-menu debe hacer fetch de los platos disponibles hoy agrupados por categoría filtrando stock mayor a 0. Crea el esquema completo de base de datos en Supabase con todas las tablas necesarias (profiles, dishes, daily_menus, orders, order_items), tipos enum para categorías, estados, métodos de pago y tipos de entrega, índices para rendimiento, Row Level Security con políticas públicas de lectura para platos y menú del día, políticas de inserción pública para pedidos y order_items, políticas de admin autenticado para todo lo demás, y un trigger que descuente automáticamente el stock en daily_menus cuando se inserta un order_item. En lib/constants.ts define RESTAURANT_NAME MenuLiz, MENU_PRICE 14, CURRENCY S/, CATEGORY_LABELS con emojis (entrada 🥗 Entradas, segundo 🍛 Segundos, refresco 🥤 Refrescos, a_la_carta 📋 A la Carta), STATUS_LABELS con emojis (nuevo 📩 Nuevo, confirmado ✅ Confirmado, en_preparacion 🍳 En preparación, en_camino 🛵 En camino, listo_para_recoger 🏠 Listo para recoger, completado ✅ Completado, cancelado ❌ Cancelado), PAYMENT_LABELS (efectivo 💵 Efectivo, yape 📱 Yape, plin 📱 Plin, lemon 📱 Lemon). En lib/whatsapp.ts crea la función generateWhatsAppMessage que recibe el pedido y los items y genera el texto con formato WhatsApp usando asteriscos para negrita, y la función openWhatsApp que abre wa.me con el número de la dueña y el mensaje codificado. Diseño UI mobile-first responsive, primario orange-500 #f97316, fondo white con secciones gray-50, cards rounded-xl shadow-sm, botones grandes touch-friendly mínimo 44px, imágenes aspect-video rounded-lg, skeletons para carga, toast notifications con Shadcn Toaster, textos en español peruano, formato de moneda S/ XX.XX. Ejecuta los comandos: npx create-next-app@latest menuliz --typescript --tailwind --eslint --app --src-dir --import-alias "@/*", luego cd menuliz, npm install @supabase/supabase-js @supabase/ssr react-hook-form zod @hookform/resolvers lucide-react html2canvas date-fns @ducanh2912/next-pwa, luego npx shadcn@latest init con estilo default y color orange, luego npx shadcn@latest add button card input label select textarea badge dialog dropdown-menu table tabs toast separator avatar skeleton.
